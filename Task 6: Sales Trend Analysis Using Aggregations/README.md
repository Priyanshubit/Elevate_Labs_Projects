## 📊 Task 6: Sales Trend Analysis Using Aggregations


## ## 🎯 Objective

Analyze monthly revenue and order volume from the online_sales dataset using SQL aggregations.

📅 Group data by Year and Month

💰 Calculate Total Revenue using SUM(amount)

📦 Calculate Order Volume using COUNT(DISTINCT order_id)

📈 Identify sales trends over time

🛠️ Tools Used



## Database: PostgreSQL / MySQL / SQLite



## Techniques: Aggregations (SUM, COUNT), Date Functions (EXTRACT, YEAR, strftime), Grouping, Sorting



## ✅ Key Learnings

⏳ How to group data by time periods (year/month)

📊 Using aggregations (SUM, COUNT DISTINCT) for revenue and volume

🗂️ Organizing results with GROUP BY and ORDER BY

🔍 Applying filters for targeted analysis
